Для защиты портфеля по курсу модуля 2 для Яндекс Такси создан эта работа.
Готовый index.html представляет собой одностраничный адаптивный сайт-презентация на Bootstrap 5, 
с каруселью, полноэкранным просмотром и ручным листанием. 
Дизайн сохранён в стиле слайдов (тёмный #1C1C1E, жёлтый #FFCC00), все 8 SVG загружаются из папки images/.
!!! Его можно использовать как шаблон-презентацию выступления через веб.
